# מייל יומי – "אמונה וביטחון"

מערכת קטנה ששולחת אליך כל בוקר (בסביבות 08:00, שעון ישראל) מייל אחד עם
הקטע היומי מתוך הקובץ, בכותרת "יום X". המערכת מדלגת אוטומטית על שבתות,
ואחרי יום 60 חוזרת להתחיל מיום 1.

הכול רץ בחינם על שרתי GitHub — אין צורך שהמחשב שלך יהיה דלוק.

## מה יש בתיקייה

- `days.json` – כל 60 הקטעים, ממוספרים.
- `send_daily.py` – הסקריפט ששולח את המייל.
- `state.json` – "זיכרון" של המערכת: איזה יום נשלח אחרון. מתעדכן אוטומטית.
- `.github/workflows/daily-email.yml` – ההגדרה שגורמת לזה לרוץ כל יום.

## התקנה (כ-15 דקות, פעם אחת)

### שלב 1: יצירת App Password בגוגל

1. ודא שיש לך אימות דו-שלבי (2-Step Verification) מופעל בחשבון הגוגל שממנו
   יישלח המייל: <https://myaccount.google.com/security>
2. גש ל: <https://myaccount.google.com/apppasswords>
3. צור סיסמה חדשה (אפשר לקרוא לה "daily-email"), וגוגל תיתן לך קוד בן 16
   תווים. **שמור אותו** — זו לא הסיסמה הרגילה שלך, ולא תוכל לראות אותו שוב.

### שלב 2: יצירת ריפו ב-GitHub

1. אם אין לך חשבון: <https://github.com/signup> (חינמי).
2. צור ריפו חדש (New repository) — אפשר Private, אין בעיה.
3. העלה אליו את **כל** התוכן של התיקייה הזו (כולל תיקיית `.github` הנסתרת!)
   — או דרך "Add file → Upload files" באתר, או דרך `git push` אם אתה מכיר.

### שלב 3: הגדרת Secrets

בריפו: Settings → Secrets and variables → Actions → New repository secret.
תוסיף שלושה:

| שם ה-Secret | ערך |
|---|---|
| `MAIL_USERNAME` | כתובת הג'ימייל ששולחת (למשל `you@gmail.com`) |
| `MAIL_APP_PASSWORD` | ה-16 תווים משלב 1 |
| `MAIL_TO` | הכתובת שאליה לשלוח (יכולה להיות אותה כתובת) |

### שלב 4: לאפשר ל-workflow לכתוב חזרה לריפו

Settings → Actions → General → גלול ל-"Workflow permissions" → סמן
**"Read and write permissions"** → Save.
(זה נדרש כדי שהסקריפט יוכל לעדכן את `state.json` בכל פעם שהוא שולח מייל.)

### שלב 5: בדיקה

טאב **Actions** בריפו → בחר "Daily Email" בצד שמאל → **Run workflow**
(הרצה ידנית) → אחרי דקה בדוק שהגיע מייל, ושה-`state.json` התעדכן ל-
`last_sent_day: 1`.

זהו. מעכשיו זה רץ לבד כל יום.

## שאלות נפוצות

**איך משנים את שעת השליחה?**
בקובץ `.github/workflows/daily-email.yml`, שני השורות שמתחילות ב-`cron:`.
הזמן שם הוא ב-UTC. יש שתי שורות (לא אחת) כי ישראל עוברת שעון קיץ/חורף —
הסקריפט דואג שלא יישלחו שני מיילים באותו יום בטעות.

**מה אם אני רוצה לדלג גם על ימי שישי, או להוסיף עוד ימים בשנה?**
ב-cron, השדה שאחרי החודש הוא ימי השבוע (0=ראשון...6=שבת). כרגע רשום
`0-5` (ראשון–שישי). אפשר לצמצם לפי הצורך.

**מה אם המייל לא הגיע יום אחד?**
בדוק בטאב Actions אם ההרצה נכשלה (X אדום) ולחץ עליה לראות את השגיאה —
לרוב זו בעיה בסיסמת האפליקציה או בשם ה-Secret.

**רוצה לערוך טקסט מסוים?**
פתח את `days.json` בריפו ועדכן את הטקסט מול המספר המתאים.
